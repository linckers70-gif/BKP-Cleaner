Ajuda

Dúvidas frequentes.

Respostas para começar a utilizar o programa.

Como instalo o BKP Cleaner Pro?

Baixe o arquivo ZIP, extraia o conteúdo para uma pasta e execute o BKP Cleaner.exe.

Posso separar a pasta _internal?

Não. Mantenha a pasta _internal no mesmo local que o executável para que os arquivos de suporte continuem acessíveis.

A limpeza é rápida?

O BKP Cleaner foi pensado para tornar o processo mais prático. O tempo real depende da quantidade de arquivos, do computador e das operações executadas.

O Windows mostrou um aviso?

O Windows pode mostrar avisos para aplicativos de desenvolvedores pouco conhecidos. Isso não confirma, por si só, se um arquivo é seguro ou perigoso. Baixe somente de uma fonte em que confia.
